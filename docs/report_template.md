# Отчёт по проекту LocalHub

## 1. Цель работы
Разработка настольного приложения для обмена данными с собственными HTTP-клиентом и HTTP-сервером на Python.

## 2. Функциональные возможности
Опишите вкладки Client, Server, Shared Files; перечислите GET/POST и файловые маршруты.

## 3. Архитектура
Вставьте диаграмму из `class_diagram.puml`. Объясните назначение `Transport`, `RequestHandler`, `HttpClient`, `HttpServer`, `Router`, `LocalHubHandler`.

## 4. Работа HTTP-клиента
Опишите разбор URL, установку TCP-соединения, сериализацию запроса, чтение и разбор ответа, таймауты и исключения.

## 5. Работа HTTP-сервера
Опишите bind/listen/accept, отдельный поток приёма, поток на соединение, маршрутизацию, формирование ответа и остановку.

## 6. GUI и многопоточность
Объясните `queue.Queue` и `root.after`; приложите скриншоты вкладок и обработки ошибок.

## 7. Безопасность
Опишите лимит заголовков 8 КБ, лимит тела 10 МБ, валидацию порта, обработку некорректного HTTP и защиту имени файла от path traversal.

## 8. Тестирование
Вставьте вывод `python -m pytest tests/ -v`, опишите unit- и интеграционные тесты.

## 9. Вывод
Укажите, какие задачи выполнены, какие ограничения остались и что можно развивать дальше.
